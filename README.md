# zaGRAj

Nadrzędna platforma do webowych gier imprezowych dla znajomych.

## Założenie

Jedno miejsce do:
- wyboru gry,
- tworzenia pokoju,
- dołączania wspólnym kodem,
- przeglądania katalogu,
- później: profili, historii rozgrywek i osiągnięć.

Poszczególne gry mogą pozostać osobnymi aplikacjami i repozytoriami. Platforma będzie ich wspólnym hubem i docelowo routerem pokojów.

## Technologia

- Next.js 16
- React 19
- TypeScript
- responsywny interfejs webowy
- docelowo osobny projekt Vercel i osobna domena

## Kierunek wizualny

Kolorowy, nowoczesny party hub z ciemną bazą, indywidualnymi kolorami gier, dużymi kartami, krótkim onboardingiem i teleturniejową energią.

Nazwa platformy: **zaGRAj**.
